# 展示字体

本机已有华文行楷时，标题优先使用系统字体；本站不分发华文行楷文件。其他设备通过本站的 Long Cang 手写体补充展示效果。

- 字体：Long Cang，Chen Xiaomin，Copyright 2018 The Long Cang Project Authors。
- 来源：https://github.com/google/fonts/tree/main/ofl/longcang
- 许可：SIL Open Font License 1.1，全文见 `OFL-LongCang.txt`。
- `long-cang-subset.ttf` 是通过 Google Fonts 的 text 参数取得的页面字符子集，包含当前页面所有汉字、英文字母和必要标点。新增标题使用未覆盖字符时需更新子集。
- 字体文件随站点发布，浏览时无需连接字体 CDN。正文和控件继续使用系统无衬线字体。
