首页采用用户选定的“项目放映厅”布局：真实作品画面配合浅青、暖杏和蓝紫渐变，切换作品时背景氛围同步变化。四个项目缩略入口通过移动底板显示选中状态；可用左右按钮、键盘左右键与 Home / End、手机横滑选择作品。纵向手势仍用于页面滚动。小屏保留完整截图与两列项目入口。

顶部以姓名字标呈现个人身份，移除介绍句与通用代码标记，让作品更早进入视野。姓名与主要标题优先使用本机华文行楷；未安装时使用随网站发布的 Long Cang 手写体子集。系统字体不随网站分发，Long Cang 来源与 OFL 许可见 [字体说明](assets/fonts/NOTICE.md)。正文最大宽度为 1240px，正文与控件使用 Segoe UI、微软雅黑等无衬线字体，保持清晰阅读和 1.75px 扁平 SVG 动作图标。

页面提供个人参与、开发过程与版本下载。工程证据支持筛选，图片只在当前项目或筛选结果内切换，支持放大、查看原图细节、恢复适应窗口、方向键切换、Escape 关闭和焦点归还；单图项目不显示翻页按钮。图片查看器提供缩略目录直接选图，手机和短高窗口默认收起目录。查看细节时可在图片区域滚动，切换图片后恢复适应窗口。选中项目写入地址参数，刷新后保留项目选择，既有案例链接仍可定位。

修图案例进一步展示上下文读取、工具规划与校验、人工确认、顺序执行、结果采用与导出五个环节，每步配真实界面截图、运行逻辑节点图和看图说明，并补充版本变化、任务中断及取消后的处理。截图覆盖会话与图层、实际工具参数、待确认状态、执行完成、导出设置。待确认与完成来自同一次运行：步骤从0/1变为1/1，画布修订从1变为2；上下文图是完成后修订2的会话结构，参数图来自已保存的完成记录。使用专用展示账号与自制海报，演示指令明确了工具和参数；此例只验证本地编辑链路，节点图用于解释实现逻辑。

水产助手支持选择知识问答、设备查询、未找到设备与水质分析四类处理分支，每类三个可点击节点说明分类、检索或调用、结果处理，并对应已有真实运行截图。节点支持上下方向键与 Home/End。它是对既有实现和记录的交互讲解，不在静态作品集执行真实查询。原六项证据筛选保留。

按钮按下、项目选择与作品切入提供即时反馈。顶部细线显示阅读进度，向下阅读后出现返回顶部按钮。GSAP ScrollTrigger 负责舞台退远与案例的一次性出场，不锁定页面滚动；页面尊重系统“减少动态效果”设置，不自动轮播。

运行图解默认逐步阅读，支持五步页签、前后步骤、方向键与 Home/End，也可展开全部内容。执行环节提供同一次翻转前后截图的画布局部对比，可用鼠标、触屏或键盘调整分界，并分别放大完整截图核对状态。画布局部通过 CSS 对齐，不修改原截图，也不在静态页面执行修图。章节导航随阅读位置更新，并按当前项目显示可用入口；切换动效遵循减少动态效果偏好。

底部“技术与实践”分为接口与任务、检索与工作流、交互与交付，说明具体项目参与和学习内容，并提供对应案例入口。保留学习状态，移除泛化引导句、进度标签和重复提示，不额外推断个人熟练程度。联系区采用浅色背景，与主作品保持层级。

## 角色与证据范围

**AI 修图智能体**通过 AI 辅助实现。我参与需求取舍、模型方案选择、界面反馈、功能验收和开发推进；项目交付包含接口、画布、任务进程与 Docker 安装编排。项目实现情况与本人独立掌握程度分别说明，Python 和相关框架持续学习中。

修图项目当前是 Windows x64 本机运行版本，需要 Docker Desktop。云端 AI 需使用者自行配置阿里云百炼北京地域密钥、网络和模型权限，并可能产生费用。静态作品集不提供在线修图服务，也不保存或调用任何模型密钥。

**智慧水产 AI 助手**展示通过 Dify 参与的资料整理与 RAG 配置、意图分类、参数提取、设备 ID 映射、已有业务接口调用、JSON 返回处理及异常分支。知识问答引用检索内容，设备与水质数据来自已有业务 API，截图不代表商业规模或性能指标。

移动端是交互原型，服务不可用时展示网络异常，该画面不作为真实服务成功调用的证据。Web 与数字孪生案例的职责集中于页面、交互原型和迁移适配，未表述为本人开发完整生产后端、数字孪生引擎或训练识别模型。

## 本地预览

在本仓库与 `zhihui-shuichan-jiaohu-yuanxing` 共同所在的父目录启动静态服务：

```powershell
python -m http.server 8877 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8877/ai-application-engineer-portfolio/>。

保留现有 React 18.3.1 UMD、ReactDOM 18.3.1 与 Babel Standalone 7.26.10 的 CDN 方式，首次加载需要网络；无需 npm 安装或构建。页面样式位于 `assets/project.css`，组件与项目数据位于 `assets/portfolio.jsx`。固定版本 GSAP 3.15.0 及 ScrollTrigger 位于 `assets/vendor/gsap/`，来源与许可链接见同目录 `NOTICE.md`。

原型使用相邻仓库的相对路径，在共同父目录预览及同域 GitHub Pages 部署下可访问。单独将本仓库作为服务根时，需另行提供相邻原型仓库。
